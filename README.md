# 🏥 투석실 간호사 근무표 자동 생성기

간호사 이름, 연차, 교대별 최소 인원만 입력하면 **한 달치 근무표를 자동으로 만들어주는** 웹 앱입니다.
설치할 프로그램이 전혀 없으며, 파일 하나(`index.html`)만 더블클릭하면 인터넷 브라우저에서 바로 열립니다.

---

## 📌 어떻게 여나요? (가장 쉬운 방법)

1. 이 저장소에서 **`index.html`** 파일을 내 컴퓨터로 내려받습니다.
   - GitHub 화면에서 `index.html` 클릭 → 오른쪽 위 다운로드 아이콘(⬇️) 클릭
2. 내려받은 **`index.html` 파일을 더블클릭**합니다.
3. 크롬, 엣지, 사파리 같은 인터넷 브라우저가 열리면서 앱이 나타납니다. 끝!

> 💡 인터넷 연결이 되어 있어야 합니다 (화면을 그리는 도구를 인터넷에서 불러오기 때문).

---

## 🧑‍⚕️ 사용 방법 (화면 순서대로)

### 0단계. 병원 선택 (NEW)
- 맨 위 **병원 선택** 칸에서 병원을 고르면, 그 병원의 간호사·최소 인원·연차가 자동으로 불러와집니다.
- **+ 새 병원** 으로 병원을 여러 개 만들어 따로 관리할 수 있고, **✏️ 이름 변경 / 🗑️ 삭제** 도 됩니다.
- 입력한 내용은 **이 기기(브라우저)에 자동 저장**되어, 창을 닫았다 다시 열어도 남아 있습니다.
  - ⚠️ 단, 저장은 "그 기기의 그 브라우저"에만 됩니다. 다른 폰·PC에서는 보이지 않습니다.

### 1단계. 간호사 등록 / 삭제
- 이름을 입력하고 **+ 추가** 버튼(또는 Enter)을 누릅니다.
- 이름 옆 **×** 를 누르면 삭제됩니다.

### 2단계. 근무 월 & 교대별 최소 인원
- 근무표를 만들 **연도와 월**을 고릅니다.
- 데이(D)·이브닝(E)·나이트(N) 각 교대에 **하루 최소 몇 명**이 필요한지 숫자로 입력합니다.

### 3단계. 연차(휴무 희망일) 입력
- 간호사를 고르고 쉬고 싶은 **날짜(일)** 를 넣은 뒤 **+ 연차 추가** 를 누릅니다.
- 그날은 해당 간호사에게 **OFF로 고정**됩니다.

### 4단계. 근무표 만들기
- **⚙️ 근무표 자동 생성** 버튼을 누르면 아래에 한 달 달력이 나타납니다.
- **📥 Excel로 내보내기** 버튼을 누르면 엑셀 파일(.xlsx)이 다운로드됩니다.

---

## ✅ 적용되는 규칙

| 규칙 | 설명 |
|------|------|
| 교대 유형 | 데이(D), 이브닝(E), 나이트(N), 오프(OFF) |
| 일요일 | 근무 없음 — 전원 OFF |
| 월~토 | 공휴일이라도 근무 |
| 나이트 다음 날 | **데이(D) 근무를 피함** (N → D 금지) |
| 연차 | 입력한 날은 OFF 고정 |
| 최소 인원 | 교대별 하루 최소 인원을 채우도록 배정 |
| 공평성 | 근무일이 적은 사람·연속근무가 적은 사람에게 우선 배정 |

> 인원이 부족해 최소 인원을 못 채우는 날은 화면 위쪽에 **노란색 경고**로 알려줍니다.
> 이때는 간호사를 더 등록하거나 최소 인원을 낮춰보세요.

---

## 📊 결과 확인 방법
- **달력 보기**: 날짜별로 D/E/N 교대에 누가 들어가는지 한눈에 봅니다.
- **간호사별 근무 현황표**: 각 간호사가 한 달간 어떤 근무를 며칠씩 하는지(D/E/N/OFF 합계) 보여줍니다.
- **엑셀 파일**: 출력하거나 보관, 공유할 때 사용하세요.

---

## ❓ 자주 묻는 질문
- **데이터가 저장되나요?** 네. 병원·간호사·최소 인원·연차는 **이 기기(브라우저)에 자동 저장**됩니다. 단, 생성된 근무표 자체는 저장되지 않으니 결과는 엑셀로 내보내 보관하세요.
- **다른 폰/PC에서도 같은 병원 목록이 보이나요?** 아니요. 저장은 "그 기기의 그 브라우저"에만 됩니다. 여러 기기에서 함께 보려면 별도 서버가 필요합니다.
- **저장된 내용이 사라질 수 있나요?** 브라우저 기록/캐시를 완전히 지우면 사라질 수 있습니다. 중요한 표는 엑셀로 보관하세요.
- **다시 만들면 결과가 바뀌나요?** 입력(간호사·연차·최소 인원)이 같으면 결과도 동일합니다.
- **인터넷이 안 되면?** 화면 그리기 도구를 못 불러와 빈 화면이 나옵니다. 인터넷 연결 후 다시 열어주세요.
